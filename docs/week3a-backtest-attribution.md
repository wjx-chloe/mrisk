# 第 3 周 A 段：假设损益 + 回测 + VaR 差异归因

## 1. 做了什么

```
position / daily_price ─► jobs/pnl.py ─────► pnl_hypo          持有 t 日收盘持仓到 t+1 的假设损益
                                               │
risk_result (VaR at t) ───────────────────────┤
                                               ▼
                          jobs/backtest.py ─► backtest_result   滚动 250 观测：Kupiec、Christoffersen、红绿灯
position / daily_price ─► jobs/attribution.py ► var_attribution  VaR/ES 日变化 = 数量 + 重估 + 窗口，个股 Euler 贡献

jobs/gate.py：四张派生表各自登记"一行依赖哪些价格日、哪些持仓日"，DQ 门禁和失效删除都按这份登记算
```

- **engine（纯函数）**：
  - `engine/pnl.py`：`hypothetical_pnl`，所有日期一次算完，输出三层结果；
  - `engine/backtest.py`：`exceptions`、`kupiec_pof`、`christoffersen_ind`、`traffic_light`、`rolling_backtest`；
  - `engine/attribution.py`：`risk_components`（Euler 分配）、`attribute_change`。
- **命令行**：`mrisk pnl | backtest | attribution --date D` 或 `--start S [--end E]`。
- **`mrisk daily`**：风险 → 昨日持仓的损益（今天实现）→ 截至今天的回测 → 今天的归因。

## 3. 关键设计

### 3.1 每张派生表登记自己的数据依赖（`jobs/gate.py`）

| 表 | 行日期 | 依赖的价格日 | 依赖的持仓日 |
|---|---|---|---|
| risk_result | t | t−L … t | t |
| pnl_hypo | 持仓日 t | t … t+1 | t |
| var_attribution | t | t−1−L … t | t−1 … t |
| backtest_result | 回测日 a | a−W−L … a | a−W … a−1 |

（L = 250 是 VaR 窗口，W = 250 是回测窗口，单位都是交易日。）

- **门禁** `dq_gate(dates, table)`：按登记的区间，查价格类、持仓类规则的失败，以及静态类规则最近一次运行的结果。
- **失效删除** `invalidate`：f 日某类规则失败时，删除各表中依赖区间包含 f 的行。
  - 例子：价格在 f 日出错，`pnl_hypo` 删 f−1 和 f 两天，`risk_result` 删 f 到 f+250，`backtest_result` 删 f 到 f+500。
- 门禁和删除读的是同一份登记，所以两者对"一次失败影响哪些行"的判断不会不一致。原来的 `invalidate_risk` 并进了 `invalidate`，`mrisk daily / backfill / dq` 每次跑完 DQ 都会调用它。
- **回测不单独过 DQ 门禁**：它只读已经存好、已经过了门禁的 `risk_result` 和 `pnl_hypo`。中间缺一个观测（例如某天被拦下）时，凡是窗口包含这一天的回测日都判为 `gap`，不出结果，已有的结果也会删除。序列开头观测数不足 W 时判为 `warming_up`，这是预期内的，不算错误。

### 3.2 归因的四次评估

记 V(W, P) 为在收益率窗口 W 上、用持仓市值向量 P 算出的风险指标；q 是持股数量，c 是收盘价。

| 评估 | 窗口 | 持仓市值 | 含义 |
|---|---|---|---|
| V0 | W_{t−1} | q_{t−1} c_{t−1} | 昨日的数 |
| V1 | W_{t−1} | q_t c_{t−1} | 数量效应 = V1 − V0 |
| V2 | W_{t−1} | q_t c_t | 重估效应 = V2 − V1 |
| V3 | W_t | q_t c_t | 窗口效应 = V3 − V2（V3 就是今日的数） |

- **每次评估单独调用**，不并成一次矩阵乘。这样输入完全相同的两次评估结果逐位相等，不调仓日的数量效应是精确的 0.0，而不是 1e-16。如果并成矩阵乘，BLAS 对不同列的分块可能不同，最后一位会有误差。
- **Euler 分量**：
  - 历史模拟 VaR：取线性插值所用的两个情景日，按插值权重对个股当天的损益加权；
  - ES：取尾部各日个股损益的平均。尾部为空时 ES = VaR，所以分量也取 VaR 的分量；
  - 参数法：z · e_i (Σe)_i / σ。
- 组合层的效应值直接取 engine 的 `hs_var / hs_es / param_var` 结果之差。测试保证它们与 `compute_risk` 一致，所以归因的"总变化"等于 `risk_result` 里两天的差。

## 4. 怎么验证的

`uv run pytest`：共 174 个测试，全部通过（第 2 周收尾时 150 个，本段新增 24 个）。

- **手算，精确到小数点后 4 位**：
  - **Kupiec**：T = 250、x = 7、p = 0.01。ln L0 = −34.6784229，ln L1 = −31.9299277，LR = 5.4970，p = 0.0190，大于 3.8415，拒绝；
  - **Kupiec 边界**：x = 0 时 LR = −500 ln 0.99 = 5.0252；x = T 时 LR = −500 ln 0.01 = 2302.5851；x = pT 时 LR = 0；
  - **Christoffersen**：序列 1110000000，转移计数 (n00, n01, n10, n11) = (6, 0, 1, 2)，LR = 5.7156（例外扎堆）。另外四种边界情况都得 0：π01 = π11、没有例外、全是例外、只在最后一天有一个例外；
  - **红绿灯边界**：4 / 5、9 / 10；
  - **假设损益**：2 只股票 × 3 天，含一次 10 送 10 的除权日。用后复权收益算是 0，用未复权价差会错记为 −500，测试明确断言前者。另含 t+1 停牌记 0，以及最后一天尚未实现；
  - **归因**：2 只股票、T = 4、95%。四次评估的 VaR 分别为 97 / 197.5 / 186 / 185.775，三项效应为 +100.5 / −11.5 / −0.225；个股 A、B 的四个效应分量逐一手算；ES 的三项为 +120 / −13 / 0。
- **恒等式**：
  - 三项效应之和 = 总变化（rel 1e-12）；
  - 个股贡献之和 = 组合值；
  - 归因的总变化 = 两天 `compute_risk` 结果之差；
  - Euler 分量之和 = engine 算出的总值；
  - 不调仓日的数量效应 `== 0.0`（精确相等）。
- **参照实现**：滚动回测与逐窗口循环的结果逐行一致，测试序列里含缺口和例外扎堆。
- **端到端**（假数据源）：
  - `pnl_hypo` 与库里数据的独立重算一致，跨过 920 切换日那天正常计算；
  - 回测日的结果与循环重算的 Kupiec / Christoffersen 一致，红绿灯只出现在历史模拟 × 99%；
  - 删掉一天损益后，恰好那 15 个回测日判为 gap（测试中 W = 15）；
  - 归因的总变化 = 库里 `risk_result` 的日差，`window_dropped` 日期正确；
  - 价格在 f 日失败时，各表恰好删除依赖区间内的日期；持仓在 f 日失败时，归因删除 f 和 f+1 两天；
  - daily 跑完后四张表都有当天的结果。

## 5. 真实库结果（2024-09-02 至 2026-09-18）

| 任务 | 结果 | 耗时 |
|---|---|---|
| `mrisk pnl` | 496 天（最后一个持仓日尚未实现） | 6 秒 |
| `mrisk backtest` | 247 个回测日有结果（2025-09-12 起），249 天在积累观测，没有缺口 | 5 秒 |
| `mrisk attribution` | 496 天 | 42 秒（约 85 ms/天） |

**假设损益的独立核对**：在 406 个没有除权的日子里，按"数量 × 未复权收盘价差"重算，最大偏差 7.5e-9 元。单日损益占市值的范围是 −8.89%（2025-04-07）到 +9.46%。

### 5.1 全样本回测（496 个观测）

| 方法 | 置信度 | 例外数 | 期望 | Kupiec LR | p 值 | Christoffersen LR | p 值 |
|---|---|---|---|---|---|---|---|
| 历史模拟 | 95% | 31 | 24.8 | 1.517 | 0.218 | 0.575 | 0.448 |
| 历史模拟 | 99% | **11** | 5.0 | **5.517** | **0.019** | 0.500 | 0.479 |
| 参数法 | 95% | 19 | 24.8 | 1.548 | 0.213 | 0.098 | 0.754 |
| 参数法 | 99% | 9 | 5.0 | 2.678 | 0.102 | 0.333 | 0.564 |

**历史模拟 99% 的 11 次例外**（损益发生日，括号内依次是当天损益占市值、前一天的 VaR 占市值）：

| 发生日 | 当天损益 | 前一天 VaR |
|---|---|---|
| 2024-10-09 | −7.32% | 2.22% |
| 2024-10-11 | −3.33% | 2.31% |
| 2024-11-22 | −3.87% | 2.87% |
| 2025-04-07 | −8.89% | 3.33% |
| 2025-11-21 | −3.99% | 2.83% |
| 2026-01-30 | −2.70% | 2.68% |
| 2026-03-23 | −4.82% | 2.72% |
| 2026-05-14 | −3.40% | 3.16% |
| 2026-06-08 | −3.76% | 3.46% |
| 2026-06-26 | −4.17% | 3.69% |
| 2026-08-19 | −3.74% | 3.68% |

参数法 99% 的 9 次例外是上表的子集：少了 2024-10-11 和 2026-01-30。

**解读**：
- 历史模拟 99% 在 5% 显著性水平下被 Kupiec 拒绝：例外偏多，VaR 偏低。
- 两种方法的独立性检验都不拒绝，例外没有明显扎堆。
- 参数法 99% 例外更少。一个原因是它的 VaR 在大跌日之前更高：2024-10-09 那天，参数法给的是 3.35%，历史模拟只有 2.22%。

### 5.2 滚动 250 观测（2025-09-12 至 2026-09-18，247 个回测日）

- **红绿灯（历史模拟 99%）**：
  - 2025-09-12 至 2026-06-05 为绿区，例外 2–4 个，共 173 天；
  - 2026-06-08 至 2026-09-18 为黄区，例外 5–7 个，共 74 天；
  - 最新回测日 x = 7，LR = 5.497，p = 0.019，Kupiec 拒绝。
- **参数法 95%**：2025-09-12 至 2026-05-13 期间，Kupiec 在 55% 的回测日拒绝。原因不是例外太多，而是太少：期望 12.5 个，实际只有 3–6 个，说明 VaR 偏保守。Kupiec 是双侧检验，两个方向都会拒绝。
- **独立性检验**：所有方法、所有回测日都不拒绝。

### 5.3 归因（历史模拟 VaR99）

- **数量效应**：496 天里 313 天精确为 0.0，正好是没有调仓、股数也没变的日子。
- **哪个效应最大**（按绝对值）：重估效应 456 天，数量效应 28 天，窗口效应 12 天。
- **平均绝对效应**（占市值）：重估 4.48 bp，窗口 1.08 bp，数量 0.38 bp。

窗口效应虽然很少是当天最大的，但大跌日移出窗口那天会非常大：

| 日期 | 移出的日期 | 窗口效应 | 重估效应 | 合计 |
|---|---|---|---|---|
| 2025-10-20 | 2024-10-09 | −0.406% | +0.036% | −0.368% |
| 2025-10-22 | 2024-10-11 | −0.371% | −0.037% | −0.409% |
| 2026-04-17 | 2025-04-07 | −0.445% | −0.024% | −0.469% |

2026-04-17 当天 ES99 的窗口效应是 −1.971%。这与上份限额材料里"断崖全部来自窗口变化"的结论一致，现在由系统逐日记录，不用再临时手算。

## 6. 已知局限 / 待确认

1. **2018 年情景的基准日（B 段需要你定）**：
   - 按股票池 80 只股票的等权收益看，最高收盘在 **2018-01-24**；之后 01-25（−0.98%）、01-26（−0.17%）、01-29（−2.14%）连跌三天。
   - 按"基准日 = 下跌开始前的最高收盘"这个标准，与 2015 年取顶点、2020 年取 01-22 一致，基准日应改为 2018-01-24。
   - 原定的 01-29 本身是下跌日，从 01-29 收盘算起会漏掉当天的 −2.14%；从 01-26 收盘算起会漏掉 01-25、01-26 两天的小跌。
   - 2020 年按 01-22 收盘算起后，情景只剩两个交易日（01-23 −3.20%、02-03 −8.07%）。
   - SPEC §6.1 等你确认后再同步。
2. **历史模拟 VaR 的 Euler 分量噪声大**：它只取决于两个情景日，某天个股贡献排第几，很大程度上取决于那两天的个股表现。
3. **回测只有假设损益**：没有真实成交，所以无法区分"持仓变动带来的损益"。这是 mock 持仓的限制。
4. **其他机器上的旧库**：库里会多一列全是 NULL 的 `risk_result.pnl_actual`，不影响读写；需要时执行 `ALTER TABLE risk_result DROP COLUMN pnl_actual`。
5. **DQ 门禁按日期判断，不按股票**（沿用第 2 周 §7 第 6 条）。
